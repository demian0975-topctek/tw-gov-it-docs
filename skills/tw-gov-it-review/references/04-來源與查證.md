# 官方來源與查證狀態

本檔是本組 skill 所引用官方文件的**出處清單**，供 `scripts/check_sources.py` 比對頁面是否已改版。

**寧可只寫法規全名而不寫版本，也不要寫錯版本。** 必須寫版本號時以本表為準並自行複查——官方文件引用官方文件的舊版是常態，不是例外。

## 怎麼用

```bash
python scripts/check_sources.py              # 逐項連線比對
python scripts/check_sources.py --list       # 只列清單，不連線
python scripts/check_sources.py --只看異動   # 只列需要人工確認的項目
python scripts/check_sources.py --嚴格       # 連不上也視為未通過（送件前用）
```

- `[異動]`——官方頁面已有更新版本，**該版本號在審查報告中不可引用**。離開碼 1，可用於排程。
- `[無法連線]`——**不等於沒有異動**，那幾項這次根本沒查到。預設離開碼仍為 0（政府網站偶有維護，不該讓排程紅燈），送件前查證請加 `--嚴格`，有來源連不上就回離開碼 2。
- `[相符]`——只代表無須優先處理，**不代表已確認為現行版**。

腳本不判斷新版本改了什麼，只負責提醒你去看。無網路時用 `--list` 取得網址自行查閱。

> 識別字串為「—」者不做版本比對，只確認頁面仍可連線。

下列兩列的 `[相符]` 不具意義，須另行處理：

- 經費估算編列手冊那一列的識別字串只是文件名稱，因為該頁的法規清單不列版次——它只偵測得到手冊從清單上消失，偵測不到改版，須人工開啟 PDF 看封面。
- 修正草案那一列盯的是預告公告的發文字號，草案完成立法時該頁不會變；**判斷是否已修法請看上一列的《政府採購法》現行條文修正日期**，那一列跳 `[異動]` 就表示採購法本文動了，全專案凡提及採購法之處都要複查。
