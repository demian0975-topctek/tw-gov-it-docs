# 版面、檔案格式與 Word 範本

使用者已有機關指定的 Word 範本時，**以機關範本為準**，本檔的數值只用來補機關沒規定的部分。

## 先分清楚三層規範，適用範圍不一樣

政府文件的格式規範不是一套，是三套，各自管不同的東西。**最常見的錯誤是拿管公文的規範去要求技術文件**，或反過來以為技術文件不受任何格式拘束：

| 規範 | 發布 | 管什麼 | 對標案技術文件的效力 |
| --- | --- | --- | --- |
| **《文書處理手冊》** | 行政院 | 公文的製作、程序、保密；含標點符號用法表、數字使用原則、法律統一用字表 | **不直接適用**（技術文件不是公文），但用字、標點、數字三項機關普遍要求比照 |
| **政府文書格式參考規範** | 國家發展委員會 | 公文（令、函、公告、其他公文）與證書獎狀的**版面**：紙張、邊界、字型、行距 | **不直接適用**，範圍明文限於上列文書。機關要求「比照公文格式」時照本檔第二節 |
| **ODF-CNS 15251 實施計畫** | 數位發展部 | 政府檔案文件的**檔案格式** | **直接適用**——「採購招標文件」明列在流通範圍內，見第一節 |

**判斷順序：招標文件與契約 → 機關提供的範本 → 本檔。** 前兩者有寫就照前兩者，本檔只在都沒寫時提供有官方依據的預設值。

## 一、檔案格式：ODF 是預設，不是選項

這是三套裡唯一直接管到標案文件的一條。「政府文件標準格式（ODF-CNS 15251）實施計畫（113-116 年）」（數位發展部，113 年 3 月）的名詞定義：

> **政府檔案文件流通**：包含機關網站提供民眾下載之文件、電子公文附件、電子郵件附件、**採購招標文件**及公務表單等電子檔案，**如為可編輯者，應以採用 ODF 文件格式為原則；如為非可編輯者，則採用 PDF 文件格式**。

ODF 指符合國家標準 **CNS 15251**（參考國際標準 ISO/IEC 26300 制定）之格式，常見副檔名 `.odt`、`.ods`、`.odp`、`.odg`。

**落到交付上：**

| 情境 | 檔案格式 |
| --- | --- |
| 機關發出的招標文件、工作說明書（可編輯） | `.odt` 為原則 |
| 機關發出的招標文件（唯讀） | `.pdf` |
| 廠商交付的交付文件，契約要求「可編輯檔」 | `.odt` 為原則；契約另訂 `.docx` 者從契約 |
| 廠商交付的交付文件，契約要求「唯讀檔」或簽核定稿版 | `.pdf` |

**兩件實務上會出事的事：**

- **`.docx` 改副檔名為 `.odt` 不是 ODF。** 必須用支援 ODF 的軟體另存新檔，或用 ODF 檢測工具驗過。機關端有檢測工具，交來的假 ODF 會被驗出來。
- **Word 存成 ODF 會掉東西。** 自動目錄、交互參照、部分表格樣式、頁首頁尾功能變數在轉檔時最常失真。**定稿轉檔後要逐頁看過一次**，尤其目錄與標號。這也是本檔第四節那兩個 F9 提醒在 ODF 流程下更重要的原因。

契約若明確要求 `.docx`，以契約為準——ODF 實施計畫是行政計畫，招標文件與契約的約定優先。

## 二、版面規格（機關要求比照公文格式時）

依「政府文書格式參考規範」（國家發展委員會，中華民國 105 年 4 月 1 日行政院院授發檔（資）字第 1050008178 號函修正）第四點共同格式。**該規範第三點明定範圍為公文與證書獎狀**，技術文件不在其內；以下數值是機關說「比照公文格式」時的依據。

| 項目 | 規範所定 |
| --- | --- |
| 紙張質料 | 70～80 GSM 以上米色（白色）模造紙或再生紙 |
| 紙張尺度 | 國家標準總號五號用紙尺度 **A4** |
| 書寫方式 | 紙張以直式為原則（欄位過多者得採橫式）；**由左而右、由上而下之橫書** |
| 上緣 | 2.5 公分 ± 0.3 公分 |
| 下緣 | 2.5 公分 ± 0.3 公分 |
| 右緣 | 2.5 公分 ± 0.3 公分 |
| 左緣 | 2.5 公分 ± 0.3 公分；**裝訂線至左緣保留 1.5 公分 ± 0.3 公分** |
| 字型 | 中文採**楷書**；英文及阿拉伯數字採 **Times New Roman** |
| 行距 | 10 點字→行距 10 點 ± 3 點；**12 點字→行距 15 點 ± 3 點**；16 點字→行距 28 點 ± 4 點；20 點字→行距 36 點 ± 5 點。未規定部分各機關自訂（1 英吋為 72 點） |
| 簽署原則 | 由左而右、由上而下 |

**規範自己留了調整餘地**：「因版面之限制需調整者，由各機關自訂之」——機關全銜過長需縮小字型編為一行、或跨頁單行需上移前頁時，得縮小行距處理。

**±0.3 公分不是裝飾。** 邊界 2.5±0.3 表示 2.2～2.8 公分都算合規；Word 預設的左右 3.17 公分**超出範圍**。要比照公文格式就得改，不能靠預設值。

## 三、分項標號的全形半形

《文書處理手冊》第十六點（四）「製作公文，應遵守以下全形、半形字形標準之規定」：

> **１、分項標號**：應另列縮格以**全形**書寫為 一、二、三、……，(一)、(二)、(三)……，１、２、３、……，(１)、(２)、(３)；**但其中「（）」以半形為之**。
>
> **２、內文**：(１) 中文字體及併同於中文中使用之標點符號應以**全形**為之。(２) 阿拉伯數字、外文字母及併同於外文中使用之標點符號應以**半形**為之。

拆成可執行的規則：

| 位置 | 數字 | 括號 |
| --- | --- | --- |
| **分項標號** | 全形（`１、` `２、`） | **半形** `(1)` |
| **內文** | 半形（`3 秒`、`99.5%`） | 中文內容用全形（），純英數內容可用半形 |

**這條最違反直覺**：同一份文件裡，標號的數字是全形、內文的數字是半形，而標號的括號又是半形。抄公文範例時最容易把內文數字一起變成全形。

**公文的分項標號只有四層**——一、／(一)／１、／(１)——**沒有「壹、」**。本 skill 各文件採用的五層階層（壹、一、（一）、1.、(1)）是計畫書與報告的慣例，不是《文書處理手冊》的分項標號規定；技術文件用五層沒問題，但不要說它出自文書處理手冊。

**用字、標點符號、數字用阿拉伯或中文的判斷，單一來源在 `../tw-gov-it-review/references/02-用語與表達.md`**，那裡的【檢查規則】表格同時驅動 `../tw-gov-it-review/scripts/check_wording.py`。本節只管「標號」這一層，不重複那邊的內容。

## 四、產生 Word 空白範本

### 產生單一骨架

```bash
pip install python-docx
python scripts/make_docx_skeleton.py 03 --機關 "○○部" --案名 "○○系統建置案" \
    --廠商 "○○資訊股份有限公司" -o 需求規格書.docx
```

編號對應 `assets/` 的檔名前綴（`--list` 列出全部）。

**機關端的工作說明書（13）改帶 `--承辦單位`：**

```bash
python scripts/make_docx_skeleton.py 13 --機關 "○○部" --案名 "○○系統建置案" \
    --承辦單位 "資訊處" -o 工作說明書.docx
```

腳本認得骨架標題的「（機關端）」標記，封面自動改列承辦單位而非承辦廠商，`--廠商` 對這一份不生效。

### 一次產出全部

專案基本資料改用 JSON 帶入：

```bash
python scripts/make_docx_skeleton.py --範例json > 專案.json
python scripts/make_docx_skeleton.py --all --json 專案.json --outdir out/
```

`--無標號` 關閉表格自動標號。

### 產出的版面

A4、**四邊邊界 2.5 公分**、內文標楷體 12pt、英數 Times New Roman、**固定行高 18pt**，含封面、版本紀錄表、可自動更新的目錄與表目錄、頁首機關名稱與案名、頁尾置中頁碼、表格自動標號。

邊界與行距取自第二節的規範值（12 點字行距 15 點 ± 3 點，取上限 18 點以維持可讀性）。**機關另有範本時以機關範本為準**，不要拿這組數值去否定機關的版面。

## 五、交件時要一併告訴使用者

- **開啟 Word 後按 Ctrl+A 再按 F9**（macOS 於「參考資料」更新目錄），目錄與標號才會顯示內容。
- **圖目錄按 F9 不會有變化。** 骨架還沒有任何「圖」標號，預先放功能變數會讓 Word 顯示「找不到圖表目錄項目」，所以那個位置放的是【待填】指引；等文件插入圖片並建立「圖」標號後，再依指引自行插入圖表目錄。
- 表格標號為流水號；機關若要求「表 3-1」章-序格式，需於 Word 內自行調整。
- **要交 ODF 時，轉檔後再檢查一次目錄與標號**（見第一節）。

前三項不講清楚，使用者會以為檔案壞了；第四項不講，交出去的 ODF 目錄可能是空的。

## 六、已填好內容的文件

本腳本只產空白範本。要輸出已填好內容的 Word 檔，用 docx skill，並比照第二節與第四節的版面——標楷體 12pt、英數 Times New Roman、四邊 2.5 公分、固定行高 18pt、頁首機關全銜與案名、頁尾置中頁碼。
